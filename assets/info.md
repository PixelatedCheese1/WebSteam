# Welcome to webSteam!
![webSteam Banner](/assets/banner.jpg)

This is where you can play unblocked Web games on a Steam like interface.
**I AM NOT TO BLAME IF YOU LOST YOUR SAVE DATA** If you clear your browser data your gonna clear the game's data!! Backup your savefiles using the in-games backup tool. (Not all games have this.)

## Searching
You can search game genre and developer by just typing it search area.
Examples:
`sandbox` `adventure` `strategy` `clicker` `simulator` `RopTop` `Mojang` etc.
